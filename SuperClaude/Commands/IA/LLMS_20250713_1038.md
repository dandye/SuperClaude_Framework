# LLMS.md

This file helps AI coding assistants understand the purpose and context of this directory.

## Purpose

The `info-arch/` directory contains information architecture tools and methodologies specifically designed to help AI assistants better understand and organize complex document structures and repositories.

## Key Files

- `info-arch.md`: Comprehensive guide to information architecture artifacts for complex document analysis (taxonomies, ontologies, content inventories, etc.)
- `md_w_yaml_frontmatter.md`: Best practices for using Markdown with YAML frontmatter for structured documentation
- `ord-mode.md`: Documentation organization and structure guidelines
- `thesaurus.md`: Controlled vocabulary and term relationship tools

## Core Concepts

### Information Architecture Artifacts
- **Taxonomies**: Hierarchical classification systems for organizing concepts
- **Ontologies**: Advanced knowledge representation with relationships and rules
- **Content Inventories**: Comprehensive catalogs of documents with metadata
- **Content Maps**: Visual representations of document relationships and structure
- **Cross-Reference Matrices**: Document relationship mapping for AI context

### Structured Documentation
- YAML frontmatter for machine-readable metadata
- Consistent field naming conventions for AI parsing
- Relationship definition between documents
- Version control and change tracking

## Common Tasks

- Creating taxonomies and controlled vocabularies for document collections
- Implementing structured metadata schemas using YAML frontmatter
- Building content inventories and cross-reference systems
- Organizing complex documentation for AI consumption
- Establishing information architecture standards

## AI Assistant Benefits

These tools specifically address AI limitations by:
- Providing explicit hierarchical structures
- Reducing terminology ambiguity through controlled vocabularies
- Enabling better long-range context maintenance
- Supporting multi-dimensional document classification

## Dependencies

- Markdown processing capabilities
- YAML parsing for frontmatter
- Understanding of information architecture principles
- Knowledge of document organization best practices

## Important Patterns

- Always use consistent metadata field names across documents
- Include explicit relationship definitions rather than implicit connections
- Maintain version information for both documents and schemas
- Separate metadata concerns from content through YAML frontmatter
